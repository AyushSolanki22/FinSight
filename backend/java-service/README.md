# FinSight Java Service (Spring Boot)

This service is included for a team member who will build a distinct Java backend component. It is optional for the first MVP.

Suggested responsibility: report export/rendering, scheduled report jobs, or a clearly bounded financial-domain service. Do not duplicate the AI/RAG/quant engine already owned by Python.

Create/run using Java 21 and Spring Boot 3.x. Configure `AI_SERVICE_URL` only if this service needs to call the AI service.
